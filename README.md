# 32-bit RISC-V Processor

A Verilog implementation of a 32-bit RISC-V processor developed as part of my work at the Centre of Nanoelectronics and VLSI Design.

## Overview

This project explores processor architecture by implementing key RISC-V components in Verilog and verifying their functionality through simulation.

## Features

- 32-bit RISC-V architecture
- Arithmetic Logic Unit (ALU)
- Register File
- Control Unit
- Datapath implementation
- Instruction Fetch Unit
- Verilog testbenches for functional verification

## Tools Used

- Verilog HDL
- Xilinx Vivado
- Icarus Verilog
- GTKWave
